# Move2D

A native iPadOS studio for turning layered character illustrations into rigged,
animated 2D characters — the kind of "living illustration" animation used in
gacha and visual-novel games.

Move2D is developed independently: its own project format, deformation system,
renderer, physics and export formats. It does not read or write Live2D Cubism
files.

| Area | What you get |
| --- | --- |
| **PSD import** | Layered PSD/PSB (RGB/Grayscale, 8/16/32-bit; raw, RLE and ZIP channels). Groups, names (Unicode), visibility, opacity, blend modes, clipping layers (→ masks) and layer masks are kept. Re-import a PSD later to update artwork without losing the rig. |
| **Meshes** | Auto-mesh that follows each layer's outline (adjustable density), grid and quad meshes, add/move/delete vertices, add/delete triangles, subdivide, retriangulate, lasso selection, soft-selection deformation. |
| **Deformers** | Warp (lattice) and rotation deformers, nested to any depth, wrapping any mix of meshes and other deformers. |
| **Parameters** | Custom parameters with ranges and defaults (a standard character set is included). Every mesh and deformer can bind to several parameters; keyforms are blended multilinearly, so one parameter drives many objects and parameters combine (e.g. Angle X × Angle Y). |
| **Animation** | Multiple clips, parameter tracks, keyframes with step / linear / ease / bezier curves, loop / once / ping-pong, auto-key, dope sheet and curve editor, additive tracks and layered playback, an idle-loop generator. |
| **Physics** | Pendulum-chain secondary motion. Inputs read parameters (head/body sway and tilt), outputs drive parameters (hair, clothes, accessories), so physics composes with the rig. |
| **Export** | Native `.move2d` project, PNG sequence, GIF, transparent video (HEVC with alpha or ProRes 4444; H.264 opaque), and a compact `.m2rt` runtime package with texture atlases for games. |
| **iPad UI** | Central Metal canvas, layer and deformer hierarchies, parameter panel, inspector, physics panel, timeline. Apple Pencil for editing (hover preview, double-tap tool switch, coalesced high-rate samples), two-finger pan/pinch, "Pencil only" mode, Files-app documents, ⌘Z / three-finger undo. |

## Repository layout

```
Package.swift            Swift package with the engine and editor modules
Sources/
  M2DCore/               math, RGBA images, zlib (inflate/deflate), PNG codec
  M2DPSD/                PSD/PSB reader and writer
  M2DRig/                meshes, triangulation, keyforms, deformers, evaluator
  M2DAnimation/          clips, tracks, curves, layered player, presets
  M2DPhysics/            pendulum-chain simulator
  M2DRender/             render lists + CPU rasteriser (export, thumbnails, tests)
  M2DMetal/              Metal renderer (Apple platforms)
  M2DProject/            .move2d project format, PSD → rig importer, sample art
  M2DExport/             PNG sequence, GIF, video (AVFoundation), .m2rt runtime
  M2DEditor/             editing session: commands, undo/redo, hit testing, sample rig
  move2d-cli/            headless import/export tool
App/                     the iPad app (SwiftUI); Xcode project generated by XcodeGen
Tests/                   unit tests per module
docs/                    architecture and file format specifications
```

The engine and editor logic have no UIKit/SwiftUI dependency, so they are built
and tested on Linux and macOS in CI; only `M2DMetal`, the video exporter and the
app are Apple-specific.

## Building the iPad app

Requirements: Xcode 16 or newer, iPadOS 17+.

```sh
brew install xcodegen
cd App
xcodegen generate
open Move2D.xcodeproj
```

Select the **Move2D** scheme and an iPad (or iPad simulator), set your team under
*Signing & Capabilities*, and run.

First steps in the app: create a document, then **Import PSD** — or **Open Sample
Character** to explore a fully rigged example (head turn, blinking, eye tracking,
mouth, breathing, hair physics and three animations).

## Engine tests and the CLI

```sh
swift test                          # 61 unit tests
swift run move2d-cli info character.psd
swift run move2d-cli import character.psd Character.move2d --spacing 40
swift run move2d-cli sample Sample.move2d
swift run move2d-cli export Sample.move2d idle.gif --clip Idle --size 512
swift run move2d-cli export Sample.move2d frames --format png
swift run move2d-cli export Sample.move2d sample.m2rt --format m2rt
```
